# Telco Customer Churn Predictor

> Predict which customers will leave — with 83.9% ROC-AUC using RandomForest + ColumnTransformer Pipeline

[Demo](demo.png)

### Live Demo
Run locally with Streamlit: `streamlit run app.py`

### Problem
Telco companies lose 20-30% customers yearly. It costs 5x more to acquire new customer than retain old one. 
Goal: predict **Churn = Yes/No** before they leave, so business can offer retention.

### Dataset
**IBM Telco Customer Churn** - 7,043 customers, 21 columns
- Source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- Target: `Churn` (Yes/No) -> 26.5% churn, 73.5% no churn (imbalanced)
- Features: 
  - Numeric: tenure, MonthlyCharges, TotalCharges, SeniorCitizen
  - Categorical: Contract, InternetService, PaymentMethod, TechSupport, OnlineSecurity, etc.

### What I Learned (Key Skills)
- **ColumnTransformer**: Different preprocessing for numeric vs categorical (real-world tables)
- **OneHotEncoder**: Turn Contract, InternetService into 0/1 columns
- **Stratified Split**: Keep 27% churn rate in train and test
- **Imbalance handling**: `class_weight='balanced'` instead of dummy accuracy
- **Metrics that matter**: Precision, Recall, F1, ROC-AUC, Confusion Matrix - not accuracy
- **GridSearch -> Hard-code**: Search best params, then ship with fixed params for speed

### Final Model
**Pipeline: Imputer + Scaler/OneHot + RandomForestClassifier**

Best params found with GridSearchCV (StratifiedKFold 5, scoring=F1):
```python
RandomForestClassifier(
    n_estimators=200,
    max_depth=10,
    min_samples_leaf=2,
    class_weight='balanced',
    random_state=42
)
```

**Business translation:**

- Accuracy 76% is NOT the main metric due to imbalance

### How to Run

1. **Clone & install:**
```bash
git clone https://github.com/ElbasanJashari/telco-churn-predictor.git
cd telco-churn-predictor
pip install -r requirements.txt
```

2. **Download data:**
Download `WA_Fn-UseC_-Telco-Customer-Churn.csv` from Kaggle and put in `data/`

3. **Train (3 seconds - best params hardcoded):**
```bash
python src/train.py
```

4. **Run app:**
```bash
streamlit run app.py
```
